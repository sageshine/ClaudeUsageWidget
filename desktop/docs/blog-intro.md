# 코딩 한 줄 못 짜는 내가, 내 컴퓨터에서 매일 쓰는 위젯을 만들었다

## "지금 몇 % 썼지?"라는 질문이 하루에도 몇 번씩

Claude를 매일 쓰다 보면 은근히 신경 쓰이는 게 하나 있다. 지금 이 세션에서 얼마나 썼는지, 이번 주 한도는 얼마나 남았는지 궁금할 때마다 브라우저 탭을 새로 열고, 로그인 상태를 확인하고, 설정 페이지 어딘가를 뒤져야 한다.

작업에 몰입해 있을 때는 이 몇 초의 전환이 생각보다 크게 느껴진다. 하던 생각의 흐름이 끊기고, 다시 원래 작업으로 돌아오는 데 또 시간이 걸린다.

그래서 만들었다. 바탕화면에 항상 떠 있으면서, 지금 사용량이 얼마인지 한눈에 보여주는 작은 위젯을.

## 개발자가 아닌 내가 어떻게?

나는 사회복지사 출신이고, 지금은 장기요양 현장을 위한 서비스를 만들고 있다. 코드를 전문적으로 배운 적은 없다. 그런데도 이 위젯을 직접 만들 수 있었던 건 Claude Code 덕분이다.

"이런 게 있으면 좋겠다"는 생각을 문장으로 옮기면, 그걸 실제로 동작하는 프로그램으로 바꿔주는 과정을 여러 번 반복했다. 디자인이 마음에 안 들면 다시 다듬고, 버그가 보이면 원인을 찾아 고쳤다. 개발자가 아니어도 내가 원하는 도구를 내 손으로 만들 수 있다는 걸, 이 프로젝트를 통해 실감했다.

## 세 가지 얼굴 중 골라 쓰는 위젯

기능만 채워 넣는 걸로는 성에 차지 않았다. 매일 들여다볼 물건이라면, 볼 때마다 기분 좋은 모습이었으면 했다. 그래서 위젯 디자인을 세 가지로 만들고 취향대로 고를 수 있게 했다.

- **테트리스** — 사용량이 쌓일수록 조각이 채워지는 통통 튀는 젤리 스티커 병
- **모래시계** — 시간이 흐르듯 모래가 내려오는 작은 캐릭터
- **숫자** — 군더더기 없이 퍼센트 숫자만 깔끔하게

세 스킨 모두 상태에 따라 표정과 움직임이 달라진다. 여유로울 땐 느긋하게, 한도에 가까워질수록 조급하게 움직인다. 숫자를 읽지 않아도 리듬만으로 지금 상태를 감으로 느낄 수 있게 하고 싶었다.

## 안전하게 쓰는 법부터 챙겼다

이 위젯은 Claude.ai가 공식적으로 열어둔 창구가 아니라, 로그인했을 때 브라우저에 남는 세션 값을 읽어서 동작한다. 그래서 처음 설계할 때부터 이 부분을 가장 신경 썼다.

- 세션 값은 Windows 자격 증명 관리자에 암호화해서 저장하고, 나는 물론 어떤 외부 서버로도 전송하지 않는다
- Claude.ai로만 요청을 보낸다
- 이 값이 사실상 로그인 정보와 같은 수준으로 민감하다는 걸 처음 실행할 때부터 안내한다

편리함을 위해 안전을 포기하고 싶지는 않았다.

## 지금 쓰고 있다

거창한 서비스는 아니다. 그냥 내가 매일 쓰고 싶어서 만든, 바탕화면 한구석의 작은 도구다. 하지만 필요를 느끼고, 그걸 실제로 만들어서, 지금 매일 쓰고 있다는 게 나에게는 꽤 뿌듯한 일이다.

혹시 같은 불편함을 느꼈던 분이 있다면, 이 위젯이 작은 도움이 되길 바란다.
