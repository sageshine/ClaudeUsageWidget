Windows 데스크톱 위젯

Claude 사용량 위젯 시작하기

바탕화면에 작게 떠서 지금 사용량이 얼마나 찼는지 보여줍니다. 처음 한 번만 설정하면 됩니다 — 5분이면 충분해요.

쓰기 전에 꼭 읽어주세요

이 위젯은 Anthropic이 공식적으로 지원하지 않는 방법(claude.ai가 내부적으로 쓰는 통로)으로 사용량을 읽어옵니다. Anthropic이 내부 구조를 바꾸면 예고 없이 멈출 수 있습니다.

설정에 넣는 sessionKey는 사실상 비밀번호와 같은 값입니다. 이 값을 가진 사람은 여러분의 Claude 계정에 로그인한 것과 다름없습니다. 위젯은 이 값을 Windows 자격 증명 관리자에 암호화해서 저장하고 claude.ai 외에는 어디로도 보내지 않지만, 이 값 자체를 다른 사람에게 알려주거나 캡처해서 공유하지 마세요.

STEP 01

파일 실행하기

ClaudeUsageWidget.exe를 더블클릭하세요. 파란 경고창이 뜰 텐데, 정상입니다. 개발자 서명이 없는 프로그램이면 윈도우가 항상 이렇게 물어봅니다.

백신이 경고할 수도 있습니다. 이런 방식으로 만든 프로그램이 흔히 겪는 오탐이지만, 이 파일을 준 사람을 믿을 수 있을 때만 실행하세요.

실행하면 안내창이 하나 뜨고, 이어서 설정 창이 자동으로 열립니다. 그 창은 잠시 그대로 두고 다음 단계로 가세요.

STEP 02

Chrome에서 값 두 개 찾기

위젯이 여러분의 사용량을 읽으려면 여러분의 로그인 정보가 필요합니다. Chrome에 이미 저장돼 있으니 꺼내오기만 하면 됩니다.

  1. Chrome에서 claude.ai에 로그인한 상태로 둡니다.
  2. F12 키를 누릅니다. 화면 옆이나 아래에 개발자 도구가 열립니다.
  3. 위쪽 탭에서 Application을 찾아 누릅니다. (안 보이면 탭 끝의 » 안에 있습니다.)
  4. 왼쪽 목록에서 Cookies → https://claude.ai를 누릅니다.
  5. 오른쪽 표에서 sessionKey와 lastActiveOrg를 찾습니다.

쿠키 목록은 사람마다 다릅니다. 위 그림에 없는 줄이 잔뜩 있어도 정상이니, sessionKey와 lastActiveOrg 두 개만 찾으면 됩니다.

값이 아주 깁니다. 표에 보이는 글자는 중간이 잘려 있으니, 줄을 클릭한 다음 아래쪽에 펼쳐지는 전체 값을 복사하세요. 잘린 값을 넣으면 로그인이 안 됩니다.

STEP 03

설정 창에 붙여넣기

아까 열려 있던 설정 창으로 돌아갑니다. 위의 칸 두 개만 채우면 되고, 나머지는 그대로 둬도 잘 작동합니다.

1 sessionKey 붙여넣기 · 2 lastActiveOrg 값 붙여넣기 · 3 저장. sessionKey 칸은 어깨너머로 보이지 않게 점으로 가려집니다.

저장하면 잠시 뒤 바탕화면에 위젯이 나타나고 숫자가 채워집니다. 여기까지 하면 끝입니다.

STEP 04

쓰는 법

  • 옮기기 — 위젯을 끌어다 원하는 자리에 놓으면 위치를 기억합니다.
  • 자세히 보기 — 위젯에 마우스를 올리면 세션/주간이 한 줄로 뜨고, 오른쪽 버튼을 누르면 전체 목록과 새로고침·설정·종료 버튼이 나옵니다.
  • 모양 바꾸기 — 설정의 위젯 모양에서 셋 중에 고르세요.
  • 색이 곧 신호 — 파랑은 여유, 노랑은 주의, 빨강은 위험. 한도에 가까울수록 더 자주 움직입니다.

같은 사용량이라도 보고 싶은 방식으로 고르면 됩니다. 언제든 설정에서 바꿀 수 있어요.

잘 안 될 때

"재로그인이 필요해요"라고 뜹니다

sessionKey는 시간이 지나면 만료됩니다. claude.ai에서 로그아웃했을 때도 그렇습니다. STEP 02를 다시 해서 새 값을 넣어주세요. 값이 중간에 잘린 채 붙여넣어졌을 때도 같은 메시지가 뜹니다.

위젯이 안 보입니다

화면 밖으로 끌고 나갔을 수 있습니다. 작업 표시줄 오른쪽 아래 트레이 아이콘을 오른쪽 클릭 → 위젯 표시/숨김을 눌러보세요.

숫자가 0이거나 회색입니다

아직 로그인 정보가 없다는 뜻입니다. 트레이 아이콘 오른쪽 클릭 → 설정에서 두 값을 넣어주세요.

PC를 켤 때마다 자동으로 띄우고 싶어요

설정에서 PC 시작 시 자동 실행을 체크하세요. 단, 켠 다음에 exe 파일을 다른 폴더로 옮기면 자동 실행이 깨집니다 — 옮겼다면 설정에서 체크를 껐다 다시 켜주세요.

지우고 싶습니다

설정에서 자동 실행 체크를 끄고 위젯을 종료한 뒤 exe 파일을 지우면 됩니다. 저장된 로그인 정보까지 완전히 지우려면 Windows 자격 증명 관리자에서 ClaudeUsageWidget 항목을 삭제하세요.

이 위젯은 Anthropic의 공식 제품이 아니며 Anthropic과 아무 관계가 없습니다. 개인이 쓰려고 만든 도구이고, claude.ai의 비공식 통로에 의존하기 때문에 언제든 멈출 수 있습니다.
